Web development

Modern web interface with Next.js and React: reusable components, dynamic pages driven by the URL identifier, state handling and automatic data refresh with SWR. The HTML, CSS and JavaScript foundations, learned in class and validated by the freeCodeCamp Responsive Web Design certification, are tested on mobile and desktop with Chrome DevTools.

Back end, APIs and databases

API routes that receive data from the browser, OAuth 2.0 authentication with Google (Next-Auth), image uploads to Cloudinary, table modelling: users, posts, job offers, messages and mentoring links with their status. Relational databases and MySQL learned in class.

Tooling, methods and deployment

Version control with Git and GitHub, continuous deployment on Vercel, secret keys handled through environment variables, VS Code with ESLint and Prettier. On method: requirements analysis, priorities, week-by-week planning and regular validation with the teaching staff.

Security and personal data

Role-based access control (member, recruiter) checked in the database, server-side in the API routes and in the interface. Authentication delegated to Google so no password is stored. Awareness of GDPR (CNIL certificate), digital security (ANSSI SecNumAcadémie) and risk analysis (Club EBIOS).
