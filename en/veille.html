AI that helps you code:
real help or false promise?

More and more developers use artificial intelligence that writes code for them. I wanted to find out whether it really saves time, and whether it causes problems.

What is technology watch?

Doing technology watch means regularly following the news on a topic to stay up to date. In IT, everything changes fast: a developer needs to know what is coming in their job. It is also a skill required in the BTS SIO.

My question

“Does AI really save developers time, without making their work less reliable?”

Three words to follow along.

Generative AI

Artificial intelligence that creates text, images or code when you ask it something. Example: ChatGPT.

Coding assistant

An AI built into the developer's tool that suggests code while they type. Example: GitHub Copilot.

Personal data

Any information about a person (name, e-mail…). In Europe, it is protected by law: the GDPR.

What I found, in short.

2 in 3

Almost everyone uses it

About two developers in three already use AI to code. But only 7 in 100 would trust it for an important decision.

+19%

It feels faster, but not always

In one experiment, experienced developers took 19% longer with AI… while they thought they were going faster.

4 in 10

The code works, but is not always safe

About 4 times in 10, code written by AI contains a security flaw, even when it works.

GDPR

Careful with personal data

You should not give an AI private information (customers, passwords…). The French CNIL has published rules about it.

My takeaways

AI is a good tool, not an autopilot.

01

Always review

Code suggested by AI must be checked and tested before it is used.

02

Don't take it on trust

Feeling faster does not mean being faster.

03

Learn the basics

Without solid basics, you cannot tell whether what the AI suggests is right.

Study of nearly 5,000 software professionals. Good to know : Productivity is mostly self-reported.
